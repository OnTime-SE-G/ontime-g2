# Route Service

Provides route and stop data to clients and internal services.

## Responsibilities

- Route listing and lookup APIs
- Stop metadata and geometry responses
- Geospatial query support through PostGIS

## Typical endpoints

- `GET /api/v1/routes`
- `GET /api/v1/routes/{route_id}/buses`
